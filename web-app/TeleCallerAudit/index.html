Performance Dashboard

Performance Report · column reference

Required headers are matched case-insensitively using common aliases.

Master Data (M)

  • Mobile
  • Project Name
  • Lead Registration Date (LRD)
  • Next Followup Date (NFD)
  • Status — used for Draft / leads without calls
  • Telecaller Name

History Data (H)

  • Mobile
  • Project Name
  • Lead Registration Date
  • Lead Update Date (LUD) — min/max across H sets the report date range
  • Status — Not Interested, Sent to Enquiry
  • Telecalling Status — Site Visit Scheduled / Pending / Cancelled
  • Telecaller Name

Scorecard columns

  • Total Leads — Master row count + unique History Mobiles not already in Master
  • History rows — Mobile/Project are forward-filled on continuation rows; metrics use the latest row only per Mobile (STE/SVS/SVC/NI counted once per lead)
  • Active Leads — Master row count
  • Site Visited (STE) — History Status = Sent/Send to Enquiry
  • Site Visit Scheduled (SVS) — History Telecalling Status
  • Total Leads vs Site Visited (%) — Site Visited ÷ Total Leads
  • Site Visit Scheduled vs Site Visited (%) — Site Visited ÷ Site Visit Scheduled
  • Site Visit Cancelled (SVC) — History Telecalling Status
  • Not Interested (NI) — History Status
  • Overdue Leads — Master Next Followup Date before today

Status matching (case-insensitive)

  • Not Interested — History Status
  • Site Visit Scheduled / Cancelled — History Telecalling Status
  • Sent to Enquiry / Site Visited — History Status (sent to enquiry or send to enquiry)

Overdue counts Master rows where Next Followup Date is before today (calendar day). No History filter is applied.
