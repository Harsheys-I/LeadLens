Settings Changes apply to new audits after you save. Sort applies on the next Excel download.

1 · OpenAI connection

Your key stays in this browser and is sent only to OpenAI during an audit. It is never part of the GitHub Pages deployment.

2 · Run & cost

Applied to new audits. Batch size is leads per API request (project + mobile), max 20. Parallel batches keep multiple requests in flight (max 50); checkpoints still save in order.

Console cost uses audit rates. TeleCaller in-app dashboards are built from audit metrics (no separate review-model pass).

3 · Input Excel fields

Add, remove, or reorder columns. Toggle which headers to read. Mobile and Project are required. Lead Update Date is accepted for ascending arrange/export only — it is not sent to the AI.

4 · Fields sent to AI

Comments always send full chronological history. The app also sends reg (registration) and fu (first Lead Update after near-dupe filter) for the 30-minute talk SLA. Other fields default to the latest call only.

5 · AI audit rules

All default checks are listed below. List allowed error types as full text, separated by |. The model and Excel both use the same labels — no numeric codes.

6 · Output Excel & sort

Choose columns to include. Sort By / Order are read live on every download.

Dates (Lead Update Date / Lead Registration / Next Followup) sort chronologically. Default sort is Lead Update Date ascending. Filename includes the active sort. Export always keeps the same Mobile + Project together and merges those two cells across that lead’s call rows.

7 · Backup & version

Export settings as JSON before a browser reset. Import restores aliases, rules, sort, pricing and run config. API keys are never included.
